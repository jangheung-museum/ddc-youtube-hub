# 동두천시 유튜브 시민참여 허브 (제안용 시안)

2027 동두천시 공식 유튜브 운영 제안서에 첨부하는 시민참여 허브 시안 페이지입니다.
동두천시 공식 사이트가 아니며, 상단에 '제안용 시안' 띠가 표시되고 검색엔진 노출을 막아 두었습니다.

## 폴더 구성
| 파일 | 역할 |
|---|---|
| index.html | 페이지 본문 |
| styles.css | 디자인 |
| app.js | 버튼·폼·팝업 동작 |
| **config.js** | **구글폼·유튜브·SNS 주소 설정 (이 파일만 고치면 됩니다)** |
| assets/ | 로고, DDC 캐릭터 이미지 |

## 1. 깃허브에 올리고 주소 만들기 (GitHub Pages)
1. github.com 로그인 → 오른쪽 위 **+ → New repository**
2. 이름 예: `ddc-youtube-hub` → **Public** 선택 → **Create repository**
3. 새 저장소 화면에서 **uploading an existing file** 클릭
4. 압축을 푼 폴더 **안의 파일 전부**(index.html, styles.css, app.js, config.js, README.md, assets 폴더)를 끌어다 놓기 → **Commit changes**
5. 저장소 **Settings → Pages** → Source: **Deploy from a branch**, Branch: **main / (root)** → **Save**
6. 1~2분 뒤 같은 화면 위쪽에 주소가 뜹니다: `https://아이디.github.io/ddc-youtube-hub/`

> 수정할 때는 저장소에서 파일을 열고 연필(✏️) 아이콘으로 고친 뒤 Commit 하면 1분 안에 반영됩니다.

## 2. 구글폼 만들기
forms.google.com → 빈 양식. 제목 예: `동두천시 유튜브 시민참여 허브 접수`
질문을 **아래 순서와 이름 그대로** 만드세요.

| # | 질문 제목 | 유형 | 필수 | 비고 |
|---|---|---|---|---|
| 1 | 보낼 곳 | 객관식 | ✔ | 보기 4개를 **글자 그대로**: `시장에게 묻기` / `담당자에게 물어봐 주세요` / `우리 가게 추천` / `사진·영상 공모` |
| 2 | 닉네임 | 단답형 | ✔ | |
| 3 | 사는 동네 | 단답형 | | |
| 4 | 내용 | 장문형 | ✔ | |
| 5 | 영상·사진 링크 | 단답형 | | |

설정 탭에서 **'이메일 주소 수집' 끄기**, **'로그인 필요(응답 1회로 제한)' 끄기** — 켜져 있으면 페이지에서 전송이 안 됩니다.
응답 탭 → **스프레드시트에 연결**을 누르면 접수 내용이 구글시트에 쌓입니다.

## 3. 구글폼과 페이지 연결 (링크 하나만 붙여 넣기)
1. 구글폼 편집 화면 오른쪽 위 **⋮ → 미리 채워진 링크 가져오기**
2. 아래처럼 채우기
   - 보낼 곳: `시장에게 묻기` 선택
   - 닉네임: `NICK` · 사는 동네: `TOWN` · 내용: `BODY` · 영상·사진 링크: `LINK`
3. **링크 받기 → 링크 복사**
4. `config.js`를 열어 `googleFormPrefillUrl: ""` 따옴표 안에 붙여 넣고 저장(Commit)
5. 페이지 질문 폼 아래 문구가 **'구글폼으로 바로 전송돼요'**로 바뀌면 연결 완료. 시험 전송 후 구글시트에 한 줄 들어오는지 확인하세요.

> 연결 전에는 '시연 모드'로 동작합니다. 전송 성공 화면은 똑같이 나오지만 내용은 그 브라우저에만 저장됩니다.

## 4. 그 밖의 설정 (config.js)
- `youtubeChannel`: 구독하기 버튼 주소 (현재는 유튜브 검색 결과로 임시 연결)
- `videos`: 각 영상의 유튜브 ID(주소 `v=` 뒤 11자리)를 넣으면 팝업에서 바로 재생
- `sns`: 푸터 SNS 아이콘 주소

## 알아 둘 점
- 공감(♥) 숫자와 '이번 달 질문' 숫자는 시안용으로, 누른 사람의 브라우저에만 반영됩니다. 모두가 같은 숫자를 보려면 구글시트를 읽어 오는 기능을 추가해야 합니다.
- 구글폼은 파일 첨부를 외부 페이지에서 받을 수 없어서, 영상은 링크로 받습니다.
- 로고 이미지는 홍보 영상에서 잘라낸 것이라 해상도가 낮습니다. 원본(AI/PNG)으로 `assets/logo.png`, `assets/mark.png`를 교체하세요.
